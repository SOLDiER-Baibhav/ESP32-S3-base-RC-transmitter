# (ComingSoon) ESP32-S3-base-RC-transmitter
A custom-built, dual-core ESP32-S3 radio control transmitter engineered for low-latency RC drone communication over NRF24L01+. Featuring a Wi-Fi SoftAP web portal for real-time mobile browser diagnostic monitoring.
